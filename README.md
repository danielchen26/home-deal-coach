# 🏠 选房谈判助手 · HomeDeal Coach

把一次真实的购房砍价复盘(挂牌 $1,399,000 → 重挂 → 多轮降价的那套 Arlington 房,以及一套翻新再售的顶层 Condo)沉淀成的**可复用决策工具**。零依赖、单文件、数据留在本机。

## 它解决什么问题

看房时信息散落在聊天记录、截图和脑子里。这个工具把完整谈判流程结构化:

| 模块 | 作用 |
|---|---|
| 🏘️ 房源看板 | **万能输入框:粘贴 Redfin / Zillow / Realtor 链接或任意地址,一键建档生成报告**(自动解析地址、识别平台、带来源链接) |
| 🧲 粘贴解析 | 详情页可直接粘贴挂牌页全文,自动提取价格/卧卫/面积/HOA/地税/建造年份(只填空白字段) |
| 📄 一键报告 | 每套房可生成完整谈判报告(核心指标+**房价支撑七维分析**+挂牌走势+谈判阶梯+buydown 月供+comps+疑点),支持打印 / 存 PDF |
| 🔮 房价支撑分析 | **七维评分**(学区/位置/品质/同区供给/需求信号/利率敏感度/持有成本,每维 −2~+2 带证据)→ 综合支撑指数与持有期建议;报告含**退出情景测算**(−2%/持平/+2% 年化下的卖价、净回笼与持有期净成本),让"持有多久"有数据支撑 |
| 📉 挂牌历史 | 按时间录入每轮挂牌/降价/撤牌,自动算"真实在售时长"——防止被"新上市 14 天"误导 |
| 🎯 持有计划 | **先问"打算住几年"再谈策略**:短期(≤5年)目标是持有期现金流与退出流动性,长期(≥10年)是票面月供与总利息。让步偏好、buydown 选择、月供底线全部随之切换 |
| 🪜 谈判阶梯 | 起报价 → 各档上限,自动算 credit 金额、卖方到手价、**相对挂牌价的总让步 %**;按持有期提示"降价 vs credit"偏好 |
| 🧮 计算器 | 2-1 / 3-2-1 buydown 各年月供(本息/全包)、补贴资金需求、credit 覆盖测算;**缺口调平引擎**(credit 不够时给出降档 / 价格↔credit 平移 / 自掏三方案并按持有期标推荐);**持有期方案对比**;让步速查 |
| ✅ 尽调清单 | 出价前必问 13 项(持有计划、MLS 完整历史、书面报价、交割时间偏好、HOA 财务、地税核定……) |
| 📖 守则 | 第 0 问(短期 vs 长期目标函数)+ 谈价十条守则 + Seller Credit 六个注意 + 完整流程图 |

## 快速开始

**本地直接用**:双击 `index.html` 用浏览器打开即可,数据自动保存在浏览器 localStorage。

**部署成网站**(任选其一):

```bash
# 方式 A:Vercel(推荐,静态站 + 可选 serverless,零配置)
cd home-deal-coach
npx vercel deploy --prod --yes
# 可选:开启服务端充填(持牌数据 API,free tier 每月 50 次)
#   Vercel Dashboard → Settings → Environment Variables → 添加 RENTCAST_API_KEY
#   之后应用里的「服务端充填」按钮即自动启用;未设置时优雅降级,不影响其他功能

# 方式 B:Netlify 拖拽(纯静态,最简单)
# 打开 https://app.netlify.com/drop ,把本文件夹拖进去,立即得到网址

# 方式 C:GitHub Pages
git init && git add . && git commit -m "home deal coach"
# 推到 GitHub 后,仓库 Settings → Pages → 选择分支即可
```

**Railway 什么时候用?** 纯静态 + 轻量 serverless 用 Vercel 免费档就够;当需要数据库(多设备同步账户)、定时抓取、或其他常驻后端时再上 Railway。

**浏览器本地 AI(WebLLM/WebGPU)可行吗?** 技术上可行(在浏览器跑 1–3B 参数的小模型),但本应用的核心瓶颈不是"智能"而是**数据访问**:Zillow/Redfin 封锁跨域抓取,本地模型再聪明也拿不到挂牌数据。应用内所有分析(阶梯/buydown/退出情景/七维评分)已经是确定性的本地计算,零 AI 也完整工作;需要外部智能的只有"数据抓取+结构化"一步,对应三条路:外部 AI 对话(零成本)、部署版 serverless + 持牌数据 API(见上)、或人工粘贴解析。

**安装成 App**:手机浏览器打开部署后的网址 →
- iOS Safari:分享 → 添加到主屏幕
- Android Chrome:菜单 → 安装应用

已含 `manifest.webmanifest` + Service Worker,部署后支持离线使用与全屏 App 形态(file:// 本地打开时自动跳过 SW,不影响使用)。

| 🌐 书签充填器 | **永久免费且不碰运气**:在应用「数据」页把按钮拖进书签栏,之后在 Zillow/Redfin 房源页点一下书签 → 自动提取价格/卧卫/面积/HOA/地税/**价格历史** → 新标签打开应用自动充填建档。用你自己的浏览器会话,零服务器、零 API key、无抓取,任何网络都有效 |

## 关于 MLS 直连(诚实版)

MLS / IDX 数据仅对持牌经纪与授权数据商开放,个人无法直连。四条现实路径:

1. **AI 抓取导入(免费,推荐)**:把 Redfin / Zillow 链接发给 AI 助手,让它按应用「数据」页内置的 schema 生成 JSON → 一键导入
2. **本地开源抓取(实验性)**:`pip install homeharvest` 后运行 `python3 grab.py <链接> > props.json` → 应用内导入。⚠️ Zillow/Realtor 会封锁部分网络,失败属正常——换网络或回到路径 1
3. **经纪人导出**:买方经纪可从 MLS 导出完整挂牌历史与 comps(比公开页更全,含 credit 信息)
4. **部署版接数据商 API**:RentCast / ATTOM 等地址级数据(付费,需 serverless 代理,`api/property.js` 已就绪)

## 核心计算口径

- **持有期目标函数**:短期(≤5年)偏好 credit/buydown(每 $1 让步 ≈ 持有期 $1 月供减免);长期(≥10年)偏好降价(每 $1 降价约省 30 年利息 $1.4 @7% 量级)。持有年限 ≤ 补贴年数时,票面月供在计划内不会发生,但须核对"卖不掉/再融资不成"的兜底月供
- **总让步 %** = `(挂牌价 − (合同价 − credit)) ÷ 挂牌价` —— 卖方把降价和 credit 合并计算,谈判只看这个数
- **月供**:等额本息 `P·r(1+r)ⁿ/((1+r)ⁿ−1)`;buydown 第 k 年按 `票面利率 − 当年补贴点数` 全期重算(规划近似,与实际按剩余本金重算差异极小)
- **Buydown 补贴资金** = 各补贴年份 `Σ(基准月供 − 当年月供) × 12`

## 数据安全

- 全部数据仅存于本机浏览器,不上传任何服务器
- 「数据」页可导出 JSON 备份 / 导入恢复;换设备前记得先导出
- 清浏览器缓存会清掉数据,重要阶段请备份

## 免责

计算结果为谈判规划参考,不构成房产估值、贷款承诺或投资建议。实际 credit 上限、buydown 可用性以贷款机构审核为准;成交参考(comps)需自行调整差异后使用。
